# README.md
Supplementary Files for coralME v1.3 paper
==========================================

- Supplementary-File-S1

Reconstruction of the iMmy281-ME model and variants. After executing generate_files(), copy and paste all 7 manual curation files into building_data subdirectories.

- Supplementary-File-S2, S3, and S4

Generation of files, ME-model reconstruction, and simulation of GRO models. Input data is provided separately in https://github.com/ZenglerLab/iEco-GRO

- Supplementary-File-S5

Structural analysis: single-gene and single-cofactor essentiality analysis

- Supplementary-File-S6

single-cofactor essentiality analysis of an M-model
